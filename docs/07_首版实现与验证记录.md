# 琉璃海湾｜首个可玩版本 v0.1.0

2026-10-12。本文件记录当前真实实现及验证，与01–06号设计基线分开。当前为可试玩的浏览器离线版本，尚未完成真人体验验收、小红书真机适配验收或平台发布。

## 运行和交付

- 本地预览：安装依赖后执行 `npm run build`、`npm run dev`，打开 http://127.0.0.1:4188 。端口可用环境变量 `PORT` 修改。
- 不依赖开发服务的试玩：先按[快速开始](../README.md#快速开始)构建，再打开本机 `dist/index.html`；GitHub源码分支不包含构建目录。运行时无远程字体、接口或第三方脚本。
- 离线交付包：琉璃海湾-v0.1.0.zip（历史包已淘汰，当前下载见仓库Releases），解压后打开index.html。
- 自动检查：`npm test`；离线构建及检查：`npm run package`；策略诊断：`node scripts/diagnose.mjs`。

## 已实现

90秒有效操作时间，左右开船，三个在途网位，一个受控下沉网。鼠标、键盘方向键/A/D与空格、触屏按钮输入均已接入。按住下沉、松手张网；轻点最小深度320，到底1030自动张网；持续按住不连发。张网半径95，六格容量，小型生物占一格，蟹/龙虾/章鱼占两格。OPEN/HOLD阶段进行连续范围捕获，先到先得、同刻按实体ID仲裁。入网即确定归属，回船才计分，没有随机捕获失败或随机逃走。

十种可捕生物、三种跨局组合、三段出生节奏、独立稀有金尾机会、浅层机会、独立观赏层已接入。每局最多出现八种捕获类型，库中共十种，不要求单局凑齐。图鉴列出十种的分值、占格、简介与本机累计发现。

已实现主页、暂停、继续、自动暂停、阶段性快照、刷新续玩、结束收网、成绩页、本机纪录、单网最佳、新发现提示、收获图片下载。记录使用独立命名空间，单局结算幂等。页面隐藏、失焦和系统取消会暂停，保留逻辑网状态；恢复后新按下可以接管原网。存储不可用时可玩，但成绩页如实说明未保存。

画面包含精绘海湾底图、动态水面亮纹、局部水光、环境漂浮、船体轻摆、人物手臂、不同生物轮廓与附肢动作、网格展开/收拢、网内鱼获、水滴、入网涟漪和差异化得分文字。声音由本地Web Audio合成，默认关闭，用户手动开启。实际玩法实体与底图独立。

## 验证证据

纯逻辑自动测试24项通过，覆盖：目录与主题合法性、最小深度、松手位置、下沉不捕鱼、长按不连发、单受控网、三槽限制、两格目标容量、重叠网归属、回船计分、倍率、连续几何、船网分离、暂停接管、种子续存一致、90秒收尾、坏存档、30个种子的完整局不变量、过载暂停、幂等存储及30/60Hz渲染节奏一致性。

Chromium浏览器验证：

- 390×844手机视口完成整局脚本：635分、42只、最佳一网108分、3个新发现；结果页、十种图鉴和刷新后的635分纪录一致，收集到的pageerror为空。
- 以上为实际模拟与页面输入产生的结果，使用浏览器虚拟时钟加速，不能据此声称真实设备90秒性能或真人体验达标。
- 双指输入：一指左移、一指按住撒网；0.7秒后仅松开撒网指，另一指继续移动。结果一张网完成回收、船到左边界80，没有多投网。
- 页面暂停期间虚拟时间推进不消耗局内时间；保存回岸、继续存档可恢复。
- 桌面与手机截图人工检查；首轮桌面底部溢出与手机成绩面板空间不足已修正。当前成绩面板独立覆盖视口并可滚动。
- 系统touchCancel在持网时暂停，并保留未张网状态；成绩图片下载已通过浏览器download事件验证。下载验证使用已结束时间的边界快照，不算额外真人/整局证据。
- 最终离线ZIP为239,831字节；静态产物合计279,053字节。
- 静态产物检查确认无运行时外部URL与eval，产物含全部底图资源。脚本构建目标为ES2017/Chrome61；实际旧Android/iOS设备仍须测试。

## 数值诊断与本轮调整

使用100个固定种子、每个种子四种策略。观察脚本仅看当前可见位置/速度，不读取出生计划或未来随机结果。分数为100局均值，比例按各策略所有撒网汇总。

| 策略 | 平均分 | 平均捕获数 | 平均网数 | 空网率 | 满载率 |
|---|---:|---:|---:|---:|---:|
| 站桩固定浅网 | 1028 | 69 | 92 | 71.9% | 1.3% |
| 往返移动固定浅网 | 834 | 55 | 92 | 80.0% | 2.0% |
| 站桩固定深网 | 340 | 6 | 32 | 89.4% | 1.7% |
| 观察后选位置/深度 | 2360 | 114 | 57.56 | 40.8% | 10.5% |

初版观察脚本满载3.7%，普通群体改为3–6只小编队，大型目标为2只、25%编队为3只。仍使用原捕获半径、窗口、空间容量和实体上限；没有在捕获时抽奖或补鱼。最终观察脚本满载10.5%，空网40.8%，属于待真人检验的初值。盲投空网较多说明观察有效，也提示新手引导仍是下一轮体验重点；不能把脚本当作真实新手或留存数据。
