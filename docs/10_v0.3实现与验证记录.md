# 琉璃海湾 v0.3 实现与验证记录

本文件记录实际交付范围，优先于旧设计稿中的三网位规则。v0.3 保留 v0.2 的完整抛网动作和统一海湾画风。

## 这一版已经可用

- **一次一张网**：抛出、下沉、收拢、回船是同一个完整循环。回船之前拒绝再次抛网；仍可移动渔船。原网处于下沉阶段时，暂停后可按住接管并松手收拢。旧存档中的最多三张在途网先正常收回，全部回船后按新规则继续。
- **声音**：原创 88 BPM、D 大调五声音阶的 32 小节循环，约 87 秒；铃音分音与木质拨弦分层，旋律及和弦变化。抛网布料声、落水噪声、水下收拢、回船木质轻响、鱼获短乐句、徽章铃音。配乐、音效、海浪分别保存开关。离开页面暂停声音，回到游戏通过用户操作恢复。
- **32 枚可获得徽章**：A01–A08、B01–B08、C01–C08、D01–D08，四个系列。Canvas 绘制独立生物、搭配和纪念图案；已获得可佩戴最多三枚，展示于首页和分享卡。其余 88 枚仍为设计内容，没有伪装成已经可获得的奖励。
- **真实奖励统计**：单网回船后记录种类搭配、大小组合和满载；正式局结束统一提交徽章、鱼获、战绩与来信进度。同一 runId 重复结算不重复领奖。旧图鉴回填可靠的初见徽章；不会由旧分数猜测历史搭配或完整出海次数。
- **海湾来信**：三种可选的跨局小目标，累计鱼获、非空网和混合网。没有断签或倒计时。完成获得纪念邮戳；完成后玩家可重新接信，切换会清空当前信件进度。邮戳没有数值加成，当前版本还没有兑换装饰。
- **战绩**：最近 60 局积分曲线和详情，新记录包含鱼获、网数、满载及最佳单网。旧版仅保存积分的记录如实显示。可重玩相同随机种子与遭遇主题，仍按普通正式局记录。
- **存档**：保留自动存档和暂停恢复，新增立即保存、JSON 备份导出、读取预览和用户点击恢复。读取时验证格式与进行中的局；写入失败尝试回滚本机记录。
- **分享和反馈**：生成包含佩戴徽章的收获图片；设备支持 Web Share 文件分享时调起系统分享，否则下载图片。反馈可编辑，复制失败则导出文本草稿，由玩家自行发送；没有绑定开发者收件服务。

## 实现边界

当前交付是浏览器离线版本。未接入小红书宿主的原生发布、相册、互动反馈 API，也没有云同步。音色采用 Web Audio 分音合成与滤波噪声，属于可玩的原创配器版本，不是录制的真实乐器音源或已经完成听感验收的商业配乐。没有开关声音前不会自动播放。

小屋装饰、潮汐景色、观察生物收集、更多来信、后续 88 枚徽章不在本版已实现列表。单网节奏会改变旧的得分与空网率，旧版机器人诊断结果不可用来评价新版平衡；需要后续真实玩家试玩。

## 验证

- `npm test`：37 项通过。新增徽章组合判定、跨局来信、重复结算、旧档回填、累计次数独立于 60 局历史、备份验证与恢复、单网完整循环和旧多网存档兼容。
- 30 个固定种子完整局检查：新版在途网数不超过 1，容量不超过 6，正确结束并结算。
- `npm run package`：离线构建与资源校验通过，无外部资源地址。
- 浏览器已验证：旧纪录和图鉴保留，初见徽章回填，佩戴后刷新保留，独立音频开关、试听入口、手动存档提示、刷新恢复入口和继续出海。实际试玩获得 90 分；本次浏览器试玩受到暂停和用户操作影响，不作为连续 90 秒性能或听感验收依据。
- 固定时间步支持 300ms 内的短暂卡顿补算，长卡顿仍暂停；已验证 200ms 不丢模拟步、长卡顿触发暂停。未做低端手机原生宿主性能验收。

运行：`npm run dev`，打开 `http://127.0.0.1:4188/`。发布包为项目根目录 `琉璃海湾-v0.3.0.zip`。
