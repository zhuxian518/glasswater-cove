# v0.2｜完整抛网与海边手绘游记

2026-10-12。响应本轮两项要求：让渔民完整抛出渔网并自然沉水；重做界面布局和全局美术，显著区别于《潜艇大战》。

## 已落地的动作

完整流程为：蓄势持网 → 挥臂抛出 → 空中展开 → 落水水花与扩散涟漪 → 加重网裙呈伞状下沉 → 松手收拢兜鱼 → 提网回船。

抛网阶段共36个逻辑tick（0.6秒）：前10tick蓄势，10–28tick为展网弧线，第28tick触发一次落水事件，28–36tick沉稳落水。人物重心、前后手臂、网面椭圆、旋转、网坠、绳线和水花均随阶段变化。蓄势期间网跟随人物；释放后从实际抛出点飞向固定投网位置，船移动不会拖拽水下网。

落水后渔网自动下沉，玩家保持按住可继续选择深度；松手后在当前合法深度兜鱼。提前松手保留请求，完成抛出并下沉到最小深度后兜鱼；到最大深度自动兜鱼。下沉时网面已经可见地展开，捕获结算只发生在玩家收拢阶段，因此界面统一改为“按住撒网 / 松手兜鱼”。六格容量、捕获半径、捕获窗口、计分倍率、十种生物与三个网位保持原规则。

姿态由模拟tick计算，暂停会停在原抛出姿态，续玩不重新投网。旧存档未保存castTicks的在途网仍使用原11tick时长，避免强制清除旧进度；新网保存36tick时长与实际抛出位置。

## 视觉统一

原来深色三栏布局改为页首题签、纸框海湾画面、独立圆润操作条、旁侧贴纸手记。手机保留主游戏与操作区。页面采用米白纸纹、海玻璃绿、陶土红、草编米金；移除深色战斗控制台的视觉关联。

背景换成水彩/水粉笔触的手绘海湾；圆润木船、渔民陶土色外套、草帽与鱼篓、带轻描边的生物、暖色网线与网坠采用一致配色。HUD改成柔和纸片牌，主页/暂停/成绩为明信片，图鉴改为浅绿和沙色自然手册，下载成绩图片也使用纸感设计。

新背景由内置imagegen生成，[提示词](design/海湾场景生成提示词-v2.txt)、[PNG源图](../public/assets/cove-background-v2.png)、[运行JPG](../public/assets/cove-background-v2.jpg)已保存在项目中。原v1资源和v0.1离线包保留，未覆盖历史源资产。正式包仅包含当前使用的v2背景。
