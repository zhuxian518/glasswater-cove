# 手机操作与鱼群视野修复

2026-10-12，基于 v0.3.1 的试玩修复。

- 按钮及其子元素显式设置 `-webkit-user-select: none`、`user-select: none`、`-webkit-touch-callout: none`。操作按钮内的图标与文字不再作为独立指针命中目标。
- 左右移动及撒网按钮阻止原生 `selectstart`、`contextmenu`、`dragstart`，并以非被动监听阻止 `touchstart` / `touchmove` 默认动作。保留原有 Pointer Events、多指开船和撒网控制。
- 将分数、遭遇主题、剩余时间与时间条从海面两侧移动至画面上方的独立状态栏。状态栏在海面 DOM 容器之外，不遮挡鱼群与渔网。
- 反馈输入框仍可编辑，未对整个页面设置全局禁选。

验证：40 项自动检查通过，包括原生长按相关事件被取消、移动与撒网同时操作正常。浏览器确认状态栏位于海面上方且无重叠，操作按钮和文字的 `user-select` 均为 `none`。已保存实际游戏画面 `output/playwright/mobile-controls-clear-sea.png`。

离线包已更新；同一 Wi-Fi 的手机试玩地址格式为 `http://电脑的Wi-Fi IPv4地址:4189/`（每台电脑需自行确认）。实际 iOS 长按行为仍需手机端复核，不将桌面浏览器检查等同于 iOS 真机验收。
