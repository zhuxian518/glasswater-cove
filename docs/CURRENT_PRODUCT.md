# 当前产品规格 · v0.4.1

截至2026-10-20的代码归档说明。本文汇总已实现范围；最初PRD/TDD和120枚徽章库保留为策划历史，不表示全部已完成。

## 目标与核心体验

轻松、有获得感的短局撒网游戏。观察鱼群、提前开船、控制下沉和收拢时机，让不同决策带来不同收获。允许空网，既不追求频繁落空，也不把每网爆满作为常态。尚无真人留存或“好玩已验证”的数据结论。

## 一局流程

1. 从准备页开始，或恢复上次出海；自动轮换三类海域组合。
2. 方向键/A/D或左右触屏按钮开船；按住空格/撒网按钮开始抛网。
3. 渔民蓄势挥臂，网在空中展开、落水；保持按住让网下沉。
4. 根据鱼群和水层松手兜鱼；网收拢后自动提回。到底也会自动收拢。
5. 回船后结算积分与捕获；这时才能再抛下一张网。移动始终可用。
6. 90秒操作结束，处理在途网后结算，记录分数、收藏、徽章及来信进度。

暂停、切后台或指针取消会清理输入并暂停；继续时处理原有在途网，不凭空生成第二张。存档恢复保留网和生物状态。

## 捕获与计分

网容量六格，小型一格、大型两格；剩一格时不能装两格生物。各物种名称、基础分、水层与容量完整表见[20种扩展记录](13_v0.4_二十种生物与徽章扩展.md)，执行配置为 `src/config/creatures.js`。

每网积分为基础分之和乘以按**只数**计算的倍率，向下取整：1只×1，2只×1.1，3–4只×1.25，5–6只×1.5。格数与只数不同，三只大生物满六格仍用三只倍率。空网0分，返船前不计入已入账得分。

## 生物与变化

20种可捕：小银鱼、青背鱼、黄鳍鱼、红鲷鱼、金尾鱼、海虾、小海蟹、鱿鱼、小章鱼、海龙虾、珍珠河豚、金纹蝴蝶鱼、蓝翼神仙鱼、绯羽狮子鱼、银翼飞鱼、蓝点鳐鱼、花纹墨鱼、珊瑚扇贝、月光海螺、翡翠皮皮虾。

6类观赏：水母、海马、海星、海胆、珊瑚、海龟，不作为可捕得分目标。三种海域组合以海草、礁石及流动水为主题，改变特色生物池。开场12秒主要遇到常见伙伴，之后特色池比例提高，末段有稀有机会。不会把20种同时塞进画面，也不保证每局都遇见全部种类。

## 收藏与持续动力

52枚徽章：初见收藏20、撒网手艺8、同网组合12、海上日常12。当前清单见[52枚导出表](design/当前徽章目录-v0.4.0.csv)，条件以配置为准。首批32枚使用精修图集，其余20枚为有独立生物/目标图案的Canvas绘制。支持放大查看、佩戴和成绩卡展示，装饰品阶不改变概率或积分。

三类跨局来信为可重复目标，完成有纪念邮戳；最高分、单网纪录、图鉴发现和最近60局手记提供后续挑战。120枚徽章、美术扩展和更大海域仍是后续设计，没有货币、付费抽奖、经营系统或云同步。

## 界面与服务功能

准备/继续、游玩HUD、暂停、结算、图鉴、徽章收藏/详情、来信、出海手记、声音与存档、分享卡、反馈草稿。海面场景不使用左右不透明卡片盖住鱼群；触屏控制保留防长按选字。海湾、纸感边框、按钮、图鉴与成绩卡采用统一视觉。

声音、音乐、环境声分别设置，默认关闭，用户操作后解锁。手动和5秒自动checkpoint；结束时提交成长并避免重复入账。普通浏览器与容器采用不同备份、分享、保存适配，详见[架构](../ARCHITECTURE.md)。
