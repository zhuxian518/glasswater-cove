# v0.3.1 徽章精修与收藏展示

## 已完成

首批 32 枚徽章全部换成独立的精绘海湾勋章。方向为高级航海纪念藏品：层叠金属边框、雕刻与绳结、海蓝珐琅、贝母珍珠、鱼鳞与触腕细节、以鱼获或海上生活为主题的小场景。保留轻松海湾的题材，不引入战争符号。

图案覆盖 A01–A08、B01–B08、C01–C08、D01–D08。徽章册使用深海绿展示衬底；新增放大藏品详情、清晰的珍藏条件和日期、佩戴与取下操作。未解锁徽章可以预览精绘全貌，但不可佩戴。详情页有轻微入场和光照变化，尊重减少动态效果设置。

“精致珍藏 / 瑰丽珍藏 / 传世珍藏”是表现层的收藏品级，没有新增抽奖概率、数值加成或收费门槛。原有徽章 ID、获得条件、玩家已获得状态、佩戴状态和存档均保留。

## 美术文件与生成方式

使用内置 **imagegen** 生成两张透明 PNG 原图；项目保留完整源图，运行时仅使用 WebP 编码版本，保留透明通道。图集逐枚测量绘制边界，避免按等分网格显示相邻徽章残片。不会为了载入美术而请求外部资源。

- [收藏与撒网手艺原图](design/徽章精修-AB-v0.3.1.png)：16 枚。
- [合奏与海上日常原图](design/徽章精修-CD-v0.3.1.png)：16 枚。
- [完整生成提示词](design/徽章精修生成提示词-v0.3.1.txt)：两组主题逐枚描述、材质、构图与透明背景约束。
- 运行资源：`public/assets/badges-ab-v3.webp`、`public/assets/badges-cd-v3.webp`。
- 渲染边界与收藏品级：`src/config/badge-art.js`。
