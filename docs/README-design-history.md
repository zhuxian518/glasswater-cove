开发预览：`npm install` → `npm run build` → `npm run dev`，打开 http://127.0.0.1:4188 。方向键/A/D开船，按住空格下网，松手兜鱼；也可用屏幕按钮与双指触屏操作。


手机局域网试玩：电脑和手机连接同一 Wi-Fi。在 PowerShell 中设置 HOST 为电脑的 Wi-Fi IPv4 地址、PORT 为 4189，再运行 npm run dev；手机打开 http://电脑IPv4地址:4189/ 。默认 HOST 仍为 127.0.0.1，仅供本机预览。不要把 127.0.0.1 或 localhost 链接当作手机地址。

自动测试：`npm test`；离线打包：`npm run package`。下文保留设计决策，当前实际实现范围以13号记录为准。

## 结论

建议复用《深海较量》的离线 Canvas H5 工程，做一款 **90 秒一局、横向开船、预判撒网、一网多鱼** 的轻休闲游戏。首版美术升级为“琉璃海湾”：精绘2.5D观感、通透水体、暖金光影、灵动鱼群与有重量感的收网动作。

技术基础可以复用，但不能仅替换贴图：捕鱼需要独立的张网、范围捕获、收网状态；潜艇反击、生命惩罚、连锁爆炸和十波数值不适合直接继承。

用户已经明确选择“轻松爽快、短局得分、保留适度技巧”，并进一步要求：**获得感来自捕鱼的过程；允许空网，但不能总打不到；满网不能泛滥；要有变化、可玩性和继续玩的理由。** 文档按这条要求设计，而非按纯刷分游戏设计。

用户进一步明确：美术、画面与动效需要更精致炫酷。因此正式视觉不再以程序几何占位为完成标准；优先制作静态关键画面与10–15秒动态切片，验证后展开精修资源。规划投入调整为15.5–23.5人日，仍为估算。

用户最新要求已纳入：海底生物多样、撒网机制丰富。v0.4替代旧版触鱼自动张网和长按连发；图示/概念图保留美术与结构用途，不能据其推断当前输入规则。

v0.4.0：可捕获生物扩展至20种、徽章扩展至52枚；新增生物的独立造型、分值、水层与海域分布，保留已有存档。详见[20种生物与徽章扩展记录](13_v0.4_二十种生物与徽章扩展.md)。

## 本稿的关键决定

| 项目 | 本稿方案 | 状态 |
|---|---|---|
| 体验方向 | 轻松、有获得感，观察与预判有效，收获有差异 | 用户已明确 |
| 平台 | 延续现有小红书小工具离线 H5，并可浏览器预览 | 依据现有项目提出的默认方案 |
| 玩法 | 90 秒操作时间；一次一张网，回船后再抛；按住沉网、松手兜鱼、自动收网 | 用户最新要求，v0.3已实现 |
| 美术 | 琉璃海湾、精绘主体、水体光影、分层动画、完整收网表现 | 提高品质投入已确认；具体方向待视觉评审 |
| 首版规模 | 一处海湾、10种可捕/6种观赏生物、三种遭遇组合、三段节奏与图鉴 | 设计建议 |
| 变化来源 | 鱼群组合、水层与松手时机、六格容量取舍、交错与稀有机会 | 首版核心 |
| 后续动力 | 单网纪录、鱼种发现、局内表现目标；后续增加潮汐变体 | 首版与后续分开 |

文中所有游戏数值和体验阈值均为**待验证初值/验收目标**，不是实测结论。没有声称已经获得真人留存、市场规模、完整竞品覆盖或平台审核结果。现有《深海较量》目录未作修改。
